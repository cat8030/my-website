# 小程序页面框架与处理逻辑（学员版）

本项目是脱敏后的微信小程序前端教学工程，包含页面结构、交互逻辑、状态管理、分享、上传、登录和接口调用示例。

## 使用方法

1. 在微信开发者工具中导入当前目录。
2. 当前 `project.config.json` 使用 `touristappid`，可用于本地学习和预览。
3. `utils/api.js` 中的 `API_CONFIG.baseUrl` 默认为空，因此智能体回复会使用本地示例逻辑。
4. 如需连接后端，请使用自己的测试域名，并自行配置微信公众平台合法域名。
5. 如需发布，请把 `project.config.json` 中的 `appid` 替换为学员自己的小程序 AppID。

## 目录说明

- `pages/`：首页、智能体、最近对话、个人中心和后台界面示例。
- `utils/agents.js`：智能体目录与本地示例回复逻辑。
- `utils/api.js`：请求、登录、上传、同步和后台接口封装。
- `utils/share.js`：微信分享菜单与分享参数。
- `utils/privacy.js`：隐私授权处理。
- `app.js`：全局用户状态、最近对话和收藏同步逻辑。
- `assets/`：页面运行所需的教学素材。

## 安全说明

本学员版不包含原项目的服务器代码、环境变量、AppSecret、API 密钥、访问令牌、用户数据、上传文件、真实客服二维码和私有开发者配置。不要把密钥写进小程序前端代码；密钥必须只保存在服务端环境变量中。
